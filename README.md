# Car Dekho Data Analysis

## Project Overview

This project analyzes the Car Dekho dataset using Python and data analysis libraries. The analysis focuses on car pricing and market characteristics.

## Objectives

- Identify the car with the highest selling price.
- Analyze important characteristics of the highest-priced car.
- Examine the distribution of cars based on fuel type.
- Visualize the dataset using charts.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains information about cars including:

- Car Name
- Selling Price
- Present Price
- Year
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

## Key Findings

- The dataset contains 301 car records.
- The highest selling price is ₹35 lakh.
- The highest-priced car is the Land Cruiser.
- Petrol cars form the majority of the dataset.

## Visualizations

The project includes a pie chart showing the distribution of cars by fuel type and other analysis outputs.
